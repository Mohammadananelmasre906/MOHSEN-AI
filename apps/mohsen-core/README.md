# MOHSEN CORE

The original MOHSEN runtime and authoritative data store.

Current beta capabilities:
- Authenticated versioned API.
- Local SQLite task and note storage.
- Task lifecycle and note search.
- Explicit command handling for a small Arabic/English command set.

No pretrained model weights are bundled. Free-form language generation remains unavailable until the independent model is implemented, trained, and evaluated. Keep Core bound to localhost in this beta.
